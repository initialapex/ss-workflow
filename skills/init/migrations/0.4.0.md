# Migration to 0.4.0

## What changes

- The skills lost the `ss-workflow-` part of their names. Before:
  `/ss-workflow:ss-workflow-new-req`, or `/ss-workflow-new-req`. Now:
  `/ss-workflow:new-req`. The same holds for `init`, `check-req`, `review`, `merge`,
  and `release`. The old names no longer exist.

   Show the other matches (READMEs, `docs/`, sections outside the managed blocks, the

   the new name. Needs the developer's answer.
